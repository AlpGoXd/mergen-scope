# Phase 2 UI proposal

Based on c126ace4f02068876f9dfae447bb21fea892ea56; configured implementation model gpt-6.1-terra. Shared control primitives and transient toast infrastructure are integrated and verified at an uncommitted checkpoint. The separately reviewed units task is included; see phase2-units.md.

`Btn` preserves legacy props and exposes neutral, chip, slate, solid and secondary variants, with destructive solid. `Controls.tsx` provides segmented choices, select, split button, menu, popover, tooltip, status message, dialog and SVG icons. `ToastProvider` offers ephemeral notifications and an optional Undo callback; no history or workspace field is introduced. Disabled segmented/menu items can expose reasons. Native select option-specific reasons are not reliably supported; use menu choices for individual disabled explanations. The full consumer migration remains in phases 4, 5 and 7, including existing toolbar select sizing (11), action roles (01), and existing frame/dialog adoption. Phase 3 owns transactional Undo.
