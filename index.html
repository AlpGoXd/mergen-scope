If your instrument saved it, it opens.

Spectrum, time domain or network: the contents of the file decide how it is read, not its extension. Open several at once, up to four panes side by side, and save the whole session as one workspace file.

.dat

Spectrum

Spectrum and signal analyser exports. The header is read too: centre, span, RBW and detector.

.csv · .txt

Time domain

Oscilloscope captures and logs, each channel against time with real units.

.s1p … .sNp

Network

Any number of ports. S, Y, Z and ABCD; dB, magnitude and phase; a Smith chart for reflections.

.tsv · anything

Any columns

Commas, semicolons or tabs. A wizard asks which column is which when it is not obvious.

A lot of analysis, built in.

Each analysis is a card beside the chart. It works on the trace you choose and updates as you zoom, and a maths result becomes a trace of its own.

Measure

  • Bandwidth
  • Ripple and flatness
  • IP3 / TOI
  • Channel power
  • Occupied bandwidth
  • Noise density
  • Peak table
  • Threshold crossings

Transform and maths

  • FFT
  • A ± B, A × B, A ÷ B
  • Smooth
  • Offset and scale

Network

  • VSWR
  • Return loss
  • Group delay
  • Stability K and μ
  • Reciprocity and isolation

Missing one? Ask for it.

Open an issue on GitHub saying what you need to measure, and it will be added.

Your files stay on your computer. Period.

No server

The app runs in your browser and reads your files there. Nothing is uploaded, ever. There is nowhere to upload to.

No cookies, no trackers, no account

Settings such as the theme are kept in your browser. The only files the site sends you are its own, and the demo files if you ask for them.

Check it yourself

Open the Network tab in your browser's developer tools, then open a file in the app. No request is made.
