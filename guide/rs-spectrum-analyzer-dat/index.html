Open Rohde & Schwarz spectrum analyzer .DAT files

Open a Rohde & Schwarz spectrum analyzer .DAT export by dropping it into the workspace. The parser reads traces and metadata including centre, span, RBW and detector; multi-trace files are supported.

This path has been tested with R&S FSVA3044 exports. Other instruments may work but are untested. If a file does not open as expected, send feedback.

Analyze a spectrum

Use markers and peak search, or add analysis cards such as IP3, Channel power, Occupied bandwidth and Noise PSD. Each tool has input requirements; see the analysis guide.
