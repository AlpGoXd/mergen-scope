How to open an oscilloscope CSV file in your browser

Open an oscilloscope waveform in CSV, TXT or TSV form and map its columns in the import wizard.

Import a waveform

  1. Open the app and drop the file into the workspace.
  2. In the import wizard, check the detected delimiter (comma, semicolon or tab) and skipped rows.
  3. Choose an X column and one or more Y columns. Set units and multipliers, and choose the time or frequency domain as appropriate.

For example:

time,signal_1kHz,signal_5kHz
0.000000,0.000000,0.000000
0.000100,0.628319,0.951057
0.000200,0.951057,0.587785

Inspect and analyze

Place markers on traces and use Waveform measurements on time data. Evenly spaced time samples can be used for FFT; its spectrum can be analyzed with Harmonics. Trace math combines two traces. Analysis tools have input requirements; see the guide below. Export plots or CSV data when ready.
