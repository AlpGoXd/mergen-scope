Frequently asked questions

Which Rohde & Schwarz .dat files can Mergen Scope open?

Mergen Scope opens ASCII trace .dat exports from Rohde & Schwarz spectrum analyzers, tested with R&S FSVA3044 exports (including multi-trace files and amplitude-only exports where Start/Stop frequency metadata rebuilds the X axis). Proprietary binary .dat captures are not parsed; export traces as ASCII .dat or CSV from the instrument.

Are my Rohde & Schwarz measurement files uploaded to a server?

No. Every .dat file is parsed and analyzed locally inside your browser with zero network requests. You can also download the single-file production build (app.html) and open it offline in an air-gapped RF lab.

What RF measurements can I run on an R&S .dat spectrum trace?

You can place normal and delta markers, run peak and minimum search, measure two-tone IP3 / TOI (with automatic F1, F2, IM3L and IM3U marker placement), occupied bandwidth, channel power, noise PSD, N-dB bandwidth, ripple, range statistics, peak tables, threshold crossings and unit-aware trace math.

Can I export Rohde & Schwarz spectrum plots to LaTeX or vector SVG?

Yes. Mergen Scope redraws each plot for print and exports standalone IEEE-sized PNG, SVG, PDF, LaTeX (pgfplots/TikZ) code and clean CSV tables.
